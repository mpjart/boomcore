How Naming Works

Clever name + base item, then the bonus from the box tier. T1 items have no bonus; T2 to T6 add +1 to +5 to a random stat.

Item Rolls Example
Weapon d100 clever name + d100 weapon Black Hawk Longbow (+2 Speed)
Armor d100 clever name + d100 armor Goblin Knee Pads (T1, no bonus)
Jewelry d100 clever name + d100 jewelry Nova's Toe Ring (+3 Charm)
Gem Gem quality for the tier + d100 gem Flawless Sapphire (T4)
  • Every weapon does the same base damage. Hands and reach set the dice (1d6 per hand for touch, 1d4 per hand for ranged), and the tier adds +N, so a bow and a slingshot differ only in how they are held. Twin weapons use both hands for one attack.
  • Base items carry their slot details: hands, touch or ranged, and physical or magical for weapons; physical or magical for armor. The app sets these when an item is equipped.
  • Armor is anything worn, from a full hazmat suit to a toe ring or knee pads.
  • Gems have no stat and no clever name; they only sell. Their quality word comes from the box tier.
  • Name rolls never explode. Names avoid the words coin, token, core, and box, because themes rename those words on screen.
  • Mix any tables. Each part of a name rolls its own table: pick a table for the clever name, then a table for the base item (or quality word and gem). In the app, the Core Master toggles which tables a loot box uses in Make a loot box; with none on, it uses Core/Fantasy. After Dark (21+) is a loot-only bonus set, made to pair with Street Grit, that mixes in the same way.
  • The Core Master can always rename an item to fit the story.
